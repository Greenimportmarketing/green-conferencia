Catálogo de produtos

Cadastrar produto

O código interno é o mesmo que aparece no PDF do pedido. Como os pedidos são em dúzias, cadastre o código de barras da dúzia (unidade pedida) e, se existir, o código de barras da caixa master — assim o sistema converte automaticamente quando alguém bipar a caixa fechada.

Importar planilha de produtos

Já preencheu a planilha modelo (Nome, Código Interno, Cód. Barras Dúzia, Cód. Barras Caixa Master, Dúzias por Caixa Master)? Envie o arquivo .xlsx para cadastrar todos os produtos de uma vez.

Publicar catálogo / backup

Depois de cadastrar ou corrigir produtos, baixe o produtos.json e substitua esse arquivo no repositório do GitHub. Isso deixa o catálogo oficializado, com histórico de todas as alterações, e faz os outros aparelhos receberem a atualização sozinhos.
